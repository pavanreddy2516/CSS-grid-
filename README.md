# CSS Grid Practice

A collection of HTML and CSS exercises focused on building layouts using CSS Grid.

## Topics Covered

- CSS Grid containers
- Grid columns and rows
- Fractional units (`fr`)
- Gaps and spacing
- Grid item positioning
- `grid-column`
- `grid-row`
- Practical grid layouts

## Files

- `grid_basic.html` — Basic CSS Grid layout with rows and columns
- `grid_proportions.html` — Different column proportions using `fr`
- `grid_span.html` — Grid items spanning multiple rows or columns
- `grid_product_layout.html` — Simple product-card grid layout
